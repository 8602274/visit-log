감시 도구 연결 안 됨

명단 사진 AI 인식 (선택)

받은 명단을 사진에서 가져올 때 쓰는 Claude API 키입니다. 키가 없으면 기기 안에서 글자를 읽는데, 인쇄된 글자는 되지만 손글씨(방명록·봉투)는 잘 못 읽습니다. 키를 넣으면 사진이 Anthropic으로 보내져 손글씨도 읽고, 사진 한 장에 몇십 원 정도 요금이 키 주인에게 청구됩니다. 키는 이 기기 안에만 저장되고 동기화되지 않습니다.
